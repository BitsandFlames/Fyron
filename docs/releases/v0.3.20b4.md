# Fyron v0.3.20b4

Released October 30, 2026 as **0.3.20 Beta 4**. Python 3.11 or newer is required.

## License change

Current Fyron source, Curate frontend/backend, and project documentation are offered under **CC BY-NC 4.0** for noncommercial use with attribution. This is source-available software, not OSI open source. Commercial use beyond existing permissions requires separate permission. Third-party licenses remain unchanged.

Previously published MIT material, including Beta 3, retains its MIT permissions. This release does not revoke those grants. See [licensing details](../repository-trust.md#license).

## Changes

- Align Python/npm metadata, Docker labels, Curate's displayed license, documentation and agent guidance.
- Add dedicated authentication guides for FHIR REST, DICOMweb, documents and PostgreSQL, including token renewal, caching, unattended use and SQL connection examples.
- Update Curate's Multer and body-parser dependencies to address GHSA-q7qp-rjg7-q26m and GHSA-27r3-jxmh-p828.
- Preserve scientific APIs. This repository begins with a fresh source snapshot; earlier Git history and release artifacts were backed up separately.

- Simplify the release history to the current release and remove the legacy CLI compatibility block from the documentation.

## Install

Install Beta 4 from PyPI:

```bash
uv add "fyron==0.3.20b4"
```

The explicit version selects the prerelease. The wheel and source archive are also attached to the GitHub release. Previously granted MIT permissions remain valid.

## Verification

See the verification report attached to the GitHub prerelease for observed checks and limitations. Tests use synthetic data and mocks, not clinical services. Passing tests do not establish clinical validity.
